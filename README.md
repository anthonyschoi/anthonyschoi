# Hi, I'm Anthony 👋

A React developer and scuba diving instructor based in Adelaide, Australia. I build software inspired by the work I do and the problems I encounter.

## 🌊 What I'm building

I'm working on **[Aqualy](https://github.com/aqualyteam)**, a SaaS platform for the diving industry.

My experience teaching and working in dive centres shapes how I approach the product: understanding everyday workflows, keeping interfaces clear, and making tools that are useful both behind the counter and out on a dive trip.

I'm also developing an interactive courseware editor for diving education, exploring how visual explanations and step-by-step presentations can make complex concepts easier to understand.

## 🛠️ Development interests

- Building web applications with **React and TypeScript**
- Designing clear interfaces for real-world workflows
- Creating visual tools for teaching and learning
- Exploring practical uses of AI in software and education

## 🤿 Beyond code

I'm a **PADI IDC Staff Instructor**, teaching in English and Mandarin, and studying **Maritime Archaeology at Flinders University**.

My interests extend to underwater heritage, 3D reconstruction, and AI-assisted interpretation of marine survey data.

These interests often overlap: diving gives me questions to explore, archaeology adds new perspectives, and software gives me ways to build something from them.
